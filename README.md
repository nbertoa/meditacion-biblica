# Meditación bíblica

Repositorio de trabajo para un libro sobre qué significa meditar según las Escrituras, cómo se expresa esa idea en las lenguas bíblicas y cómo puede practicarse concretamente con los textos.

## Propósito provisional

Investigar con profundidad, explicar con lenguaje claro y proponer prácticas utilizables. El manuscrito distinguirá lo que afirma el texto bíblico, lo que aporta la investigación léxica e histórica, las interpretaciones de autores modernos y las experiencias personales del autor.

## Estructura

- `INSTRUCCIONES_PROYECTO.md`: borrador de instrucciones para trabajar el libro dentro del proyecto de ChatGPT.
- `plan/decisiones-pendientes.md`: temas a definir antes de cerrar metodología y capítulos.
- `investigacion/`: inventario léxico, pasajes y preguntas pendientes.
- `fuentes/registro-bibliografico.md`: fuentes primarias y secundarias, con datos verificables.
- `capitulos/`: espacio para borradores separados por capítulo, una vez definida la estructura.
- `practicas/catalogo.md`: ideas candidatas, aún no seleccionadas.
- `experiencias/registro.md`: relatos personales que el autor quiera aportar.

## Estado

Etapa de diseño. Todavía no están acordados el lector, el enfoque, la metodología ni los capítulos. Los documentos existentes son materiales de conversación y no decisiones aprobadas.

## Convenciones

- Escribir en español claro y natural.
- Citar edición, página o ubicación estable para las fuentes consultadas.
- Registrar por separado evidencia, interpretación e hipótesis.
- No atribuir al texto bíblico una práctica que solo aparezca en una tradición posterior.
- En cada capítulo, mantener visible qué está confirmado, qué está debatido y qué falta investigar.
