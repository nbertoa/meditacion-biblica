# Investigación bíblica

## Inventario léxico: protocolo

La búsqueda no se limitará a las palabras que una traducción castellana vierte como “meditar”. Para cada forma relevante:

- registrar lema, forma gramatical y sistema de numeración usado;
- listar cada ocurrencia localizada y comprobarla en el texto original;
- anotar traducciones y variantes entre versiones;
- describir sintaxis, objeto de la acción, género literario y contexto;
- distinguir uso explícito de “meditar” de ideas cercanas como recordar, considerar, rumiar, reflexionar, hablar consigo mismo o atender;
- marcar casos dudosos y decisiones de inclusión/exclusión.

La tabla inicial está en `palabras-biblicas/inventario.md`. No se considerará exhaustiva hasta registrar el corpus completo y revisar falsos positivos.
